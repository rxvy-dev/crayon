crayon.h

Graphics in C, stupid easy.

Draw, make games and build little apps in C with one header file. No setup, no libraries to link, no 200 lines of boilerplate before your first pixel.

// what it does

Every feature is about one line.

Each example below is real code, and each picture is that code running. The middle of the window is (0, 0), x goes right and y goes up.

Colorful text text()

Put colors right inside the words with {red}, or make every letter a different color with {rainbow}. Emoji work too.

text.c
textsize(70);
text_center("{rainbow}Hello World!", 0, 120);
text_center("{red}red {blue}blue {green}green", 0, 10);
text_center("{white}emoji too 🔥🐢🚀", 0, -110);

Pictures that move image() { }

Put a picture on screen, then everything inside the braces moves that picture. Slide, turn left and right, spin.

move.c
image("turtle.png", -280, -100, 2) {
    move_to(280, -100);   // slide over
    lt(90);                // turn left
    move_to(280, 150);
    spin(360, 10);         // spin fast
}

A whole game, no loops on_touch()

Make a player, scatter some coins, and say what happens when you touch one. Arrow keys and WASD already work. Score, lives and a game over screen are built in.

coins.c
void got_coin(void) {
    add_score(1);
    respawn();
}

int main(void) {
    window(800, 560);
    player("turtle.png");
    spawn("coin.png", 5);
    on_touch("coin.png", got_coin);
    chase("star.png", 1);
    show_score();
    lives(3);
}

Ask, then answer userinput()

The program simply waits for the answer. Check it with strstr and show whatever you want. That's a chatbot in a few lines.

ask.c
while (1) {
    const char *input = userinput("?:");
    page();
    if (strstr(input, "linux"))
        text_center("Linux is a kernel made by {yellow}Linus Torvalds", 0, -100);
    else
        text_center("{gray}I don't know that yet", 0, -100);
}

Buttons anywhere button()

Words, x, y, and the function to run. Turn on grid() and show_coords() while you build and you'll always know where things go.

place.c
grid();
show_coords();
button_color("blue", "white");
button("Top left",  -320,  190, hi);
button("Middle",       0,    0, hi);
button("Bottom right", 320, -190, hi);

GIFs and videos image()

Same function for everything: png, jpg, bmp, animated gif, webp, even mp4 and webm. Add sound("music.mp3") for audio.

gif.c
image("btw.gif", 0, 0, 3.5);     // it animates
image("clip.mp4", 0, -200);      // it plays
sound("music.mp3");

Drawing forward()

Classic turtle drawing plus boxes, circles, fills and pictures. Use speed(0) to draw instantly.

draw.c
color("orange");
begin_fill();
repeat(3) { forward(90); left(120); }
end_fill();

// install

Three steps. No package manager.

crayon.h loads X11 and the rest by itself when your program starts, so there is nothing to link.

Download

Grab the one file into your project folder.

curl -O https://raw.githubusercontent.com/rxvy-dev/crayon/main/crayon.h

Include

Put this at the top of your .c file.

#include "crayon.h"

Build & run

Plain gcc. That's the whole build.

gcc main.c -o main && ./main

Want #include <crayon.h> from anywhere? Run sudo cp crayon.h /usr/local/include/ once. Videos, webp and sound() also need ffmpeg. Emoji need an emoji font like noto-fonts-emoji.

// cheat sheet

The whole library on one screen.

Colors can be names like "red" or hex like "#ff8800". Everything with x, y uses the middle of the window as (0, 0).

FunctionWhat it does
window(w, h) title("..")make the window, name it
background("sky") clear() new_screen()color the window, erase drawings, wipe everything for a new page
forward(n) left(deg) right(deg) go_to(x, y)move and turn the pen
color("red") thickness(n) circle(r) box(x, y, w, h)draw in color, shapes and boxes
text("..", x, y) text_center("..", x, y)words, with {red} and {rainbow} color tags
textsize(n) bold(1)size and weight of the next text
image("x.png", x, y) { .. }a picture, gif or video; code in { } moves it
move_to(x, y) move_by(dx, dy) lt(deg) rt(deg) spin(deg)slide and turn a picture or label
button("..", x, y, fn) link("..", x, y, fn)clickable buttons and words
userinput("..") pick("Yes", "No")wait for typed text or a click
inputbox("..", x, y, w, fn) entry() typed("..")a text box that runs fn on Enter
player("..") spawn("..", n) on_touch("..", fn)games with no loops
chase("..", s) add_score(n) lives(n) you_win("..")enemies, score, hearts, end screens
forever { key(UP) forward(4); }your own game loop, 60 times a second
sound("x.mp3") wait_for(sec) rnd(a, b)play audio, pause, random numbers
run("cmd %s", word) run_ok()run a terminal command, words safely quoted
